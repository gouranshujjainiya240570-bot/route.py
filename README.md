# 🚌 route.py – College Bus Tracking System

**EduTransit** is a web-based College Bus Tracking and Management System designed to make college transportation easier, safer, and more organized for students, drivers, and administrators.

The system allows students to check bus routes, pickup locations, bus numbers, driver details, and bus schedules through a simple and user-friendly interface.

---

## 🚀 Project Overview

Students often face difficulties finding the correct college bus, checking pickup points, and knowing bus timings.

EduTransit solves these problems by providing a centralized platform where students can easily access college transportation information.

**Note:** This project currently provides route and schedule information based on predefined data. It does not use live GPS or map integration.

---

## 🎯 Objectives

- Make college transportation information easily accessible.
- Help students find their correct bus and pickup point.
- Provide information about bus routes and schedules.
- Maintain driver and bus details.
- Reduce confusion and save students' time.
- Provide separate access for students and administrators.

## ⚙️ Installation and Setup

Follow these steps to run the project locally:

1. Download or clone this repository.

```bash
git clone https://github.com/your-username/EduTransit.git
```

2. Open the project folder.

```bash
cd EduTransit
```

3. Open `index.html` in your browser.

4. Explore the website and its available features.

**Recommended:** Use Visual Studio Code with the Live Server extension.

---

## 🔄 Working Process

1. Student opens the EduTransit website.
2. Student logs in to the system.
3. Student enters or selects their pickup location.
4. System displays the available bus information.
5. Student checks the bus number, route, driver details, and schedule.
6. Admin manages transportation information through the admin dashboard.
